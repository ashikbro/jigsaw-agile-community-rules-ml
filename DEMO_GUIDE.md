## 🎯 **Which Demo Should You Choose?**

### **Choose Web Dashboard If:**
- Your teacher appreciates **visual data analysis**
- You want to emphasize **technical sophistication**
- The presentation format is **formal/academic**
- You need to show **multiple model comparisons**
- Time allows for **detailed exploration**

### **Choose Chatbot If:**
- Your teacher prefers **interactive engagement**
- You want a **conversational presentation style**
- Time is limited (chatbot is faster to demonstrate)
- You want to **explain concepts simply**
- The setting is more **informal/discussion-based**

### **💡 Pro Tip: Use Both!**
Start with the **chatbot** for engagement, then switch to the **web dashboard** for detailed technical analysis!

## 🚀 **How to Run the Demos**

### **Easy Method (Recommended):**
```bash
python run_demo.py
```
This launches a menu where you can choose either demo and automatically installs dependencies.

### **Direct Method:**
```bash
# For Web Dashboard:
streamlit run web_demo.py

# For Chatbot:
streamlit run chatbot_demo.py
```

### **First Time Setup:**
If you don't have Streamlit installed:
```bash
pip install streamlit plotly lime shap
```
